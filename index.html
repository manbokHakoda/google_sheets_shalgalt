НЭГДҮГЭЭР ХЭСЭГ. СӨНГӨХ АСУУЛТУУД

Зөв хариултыг сонгоно уу. Асуулт бүр 1 оноо.

1. Мэдээллийн нийгмийн үндсэн шинж ба давуу талд аль нь хамаарах вэ?
✓ Зөв хариулт: Б — Мэдээлэл болон мэдлэгийг бүтээх, түгээх, ашиглах үйл явц давамгайлдаг.
2. Зохиогчийн эрхээр хамгаалагдсан, эх кодыг нь нээлттэй харах, өөрчлөх, үнэ төлбөргүй ашиглах боломжтой програм хангамжийг юу гэх вэ?
✓ Зөв хариулт: Б — Open Source Software буюу нээлттэй эхийн програм хангамж.
3. Алгоритмын блок схемд ашиглагддаг Ромбо хэлбэртэй блокийн гүйцэтгэх үүргийг тодорхойлно уу.
✓ Зөв хариулт: Г — Ромбо дүрс нь нөхцөл шалгах, салаалалт хийх үйлдлийг илэрхийлдэг.
4. MS Word програмд олон хуудастай том баримт бичгийн “Автомат гарчиг” үүсгэхийн тулд ямар тохиргоо заавал хийсэн байх шаардлагатай вэ?
✓ Зөв хариулт: Б — Heading 1, Heading 2 зэрэг Styles ашигласнаар автомат гарчиг үүсгэнэ.
5. MS Word дээр математикийн нарийн нийлмэл томьёо, бутархай, интеграл, язгуур оруулахдаа ямар цэс ашигладаг вэ?
✓ Зөв хариулт: Б — Insert → Equation.
6. Компьютерийн графикийн Вектор ба Растер дүрслэлийн гол ялгаа юу вэ?
✓ Зөв хариулт: Б — Вектор зураг масштаблахад чанараа хадгалдаг бол растер зураг пикселжиж болно.
7. MS Excel цахим хүснэгтийн A1-ээс A10 хүртэлх нүдний утгуудын нийлбэрийг олох зөв формулыг сонгоно уу.
✓ Зөв хариулт: А — =SUM(A1:A10)
8. MS Excel дээр ax + b = c хэлбэрийн шугаман тэгшитгэлийг бодохдоо “Goal Seek” хэрэгслийг ашигладаг. Энэ хэрэгсэл ямар цэсэнд байдаг вэ?
✓ Зөв хариулт: В — Data → What-If Analysis → Goal Seek.
9. Цахим орчинд бусдын бүтээлийг (зураг, нийтлэл, програм г.м) зөвшөөрөлгүйгээр хуулбарлан ашиглаж, өөрийн нэр дээр нийтлэх нь ямар зөрчил болох вэ?
✓ Зөв хариулт: Б — Плагиатизм буюу бусдын бүтээлийг зөвшөөрөлгүй ашиглах.
10. Хайлтын системд хайлт хийхдээ тодорхой хэллэгийг яг байгаагаар нь хайхын тулд ямар тусгай тэмдэгтийг ашигладаг вэ?
✓ Зөв хариулт: В — Хашилтын тэмдэг " " ашигласнаар тодорхой хэллэгийг яг тэр хэлбэрээр хайх боломжтой.
